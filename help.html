Quick guide

Help

Shortcuts for the parts of YouTube Music you use most.

Playlist actions

On a playlist page, hover a track to show your selected quick actions. On touch screens they stay visible. Remove, Queue, and Play next use YouTube Music’s own track menu, so an action can be unavailable for playlists you can’t edit.

Side play opens a separate YouTube Music player in a dialog. It pauses the current player and attempts to resume it at the same position when you close the dialog. This is experimental: YouTube Music may block playback in an embedded frame.

Sidebar shortcuts

Shortcuts are paths within music.youtube.com. Add a name and path in settings, for example /library/playlists. Downloads uses /browse/FEmusic_offline. Enabled shortcuts also appear in the narrow sidebar, alongside playlist artwork or fallback icons and shortened names.

Library layout

Choose List view or Grid view from the dropdown beside the Library sort control. List mode shows compact horizontal rows; grid restores the original cards. Your choice is saved automatically. Sorting and navigating away should not change layouts on other pages.

Not available yet

Picker persistence and playlist/artist/channel dialogs are not implemented. Side play is experimental. Comments use YouTube Music’s own interface; this extension does not add a separate drawer.

Report a broken control

YouTube Music changes its page markup over time. If a shortcut stops working, use the site’s native control as a fallback and reload the YouTube Music tab after updating the extension.
